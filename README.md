# Buildwright v0.1

**Private playtest sandbox** — a classless Lifepath + personal-Web character builder for the **Aegis** science-fiction setting, layered on a D&D 5.5e/3.5e-style d20 core.

**▶ Play it:** `https://YOURUSERNAME.github.io/buildwright/` *(replace YOURUSERNAME after enabling GitHub Pages)*

## What it is

- **Lifepath creator:** species → culture → childhood → education → formative experience → career. Earlier choices open and close later ones.
- **Personal Web:** ten domains — BOND, MIGHT, PARACAUSAL, SPIRIT, MIND, PASSAGE, FORM, FORGE, GUILE, SOCIETY — with fog of war. Nodes appear, lock and fade based on who the character is.
- **Experience reveals, Web Points acquire:** story events, factions, gear and mastery thresholds change what exists in the Web. Players still spend points to take abilities.
- **Use-based skills:** Progress Marks (max 1 per skill between long rests), 10 marks = +1, and mastery tiers act as qualifications.
- **Planning Mode:** theorycraft on a hypothetical copy without touching the live character.
- **Developer / Balance panel:** override anything, edit every playtest value, and inspect balance statistics.

## Status

**Everything here is TEST content.** Numbers, node costs, species and factions are placeholders for playtesting. They are not setting canon.

## Running it

- **Single file** (`index.html`).
- **No install, account, server or internet** needed once it's loaded.
- **Works offline.** Download the file and open it in any modern browser.
- **Mobile-first**, and works on desktop too.

## Saving

- **Browser storage:** characters save in the browser you use, separately per site or file location.
- **Backups:** clearing browser data erases saves. Use **Library → Export Complete Backup** regularly, and **Import Complete Backup** to restore or move between devices.

## Updating

Upload a new `index.html` to this repository (**Add file → Upload files**). The site updates within a minute or two.
